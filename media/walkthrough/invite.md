# The invite is the key

An invite looks like this:

```
REZO-3F9A1C...~k2Jd8...
```

The part after `~` is the **decryption key**. Anyone who has the invite can read the room, so:

- send it in a private DM, not a public channel
- run **REZO: Copy Room Invite** any time to copy it again
- run **REZO: Leave Current Room** to forget the key on this machine
