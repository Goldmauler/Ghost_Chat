# Pin notes to code

Select some lines and press **Ctrl+Alt+Shift+P**. Add a note, and it shows up as a review thread on that line for everyone in the room. Your file is never changed.

## All shortcuts

| Shortcut | Action |
|---|---|
| Ctrl+Alt+; | Open chat |
| Ctrl+Alt+H | Hide everything |
| Ctrl+Alt+Shift+P | Pin selection to a thread |
| Ctrl+Shift+Q | Ask AI about the selection |
| Ctrl+Alt+Shift+V | Save selection to vault (no selection: open vault) |
| Ctrl+Alt+Shift+R | Chat history |

Set your name with **REZO: Set Display Name**. Reopen this guide with **REZO: Getting Started**.
