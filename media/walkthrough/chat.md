# Chat in the terminal

**Ctrl+Alt+;** opens the chat as an ordinary-looking terminal.

```
$ hey, is the build green?
alice  yep, just merged #42
```

- Type and press **Enter** to send.
- New messages show a pop-up and a count in the status bar. Set `rezo.notify` to `silent` to keep only the count.
- **Ctrl+Alt+Shift+R** opens the full history as a document.
- **Ctrl+Alt+H** hides every REZO window instantly.
